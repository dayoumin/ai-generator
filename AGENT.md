# Agent Notes

## UI Scope

- This product is desktop-first.
- Evaluate and design the primary UX for PC screens first.
- Do not treat mobile responsiveness as a release blocker for the current phase.
- Mobile optimization can be deferred until the desktop workflow is stable and complete.

## Working Rule

- When reviewing UI/UX, prioritize desktop information architecture, task flow, clarity of state, and generation workflow efficiency before responsive polish.
