왜 서버가 2개인가?

ComfyUI는 GPU로 이미지를 생성하는 독립 오픈소스 AI 엔진입니다. AI_Generator는 ComfyUI의 API를 호출하는 관리 도구입니다. 자동차에 비유하면 ComfyUI가 엔진, AI_Generator가 운전석입니다.

Terminal Guide

2개 터미널을 구분하는 방법

Terminal 1: ComfyUI (AI Engine)
"To see the GUI go to: http://0.0.0.0:8188" "got prompt" "100%|████████| 20/20 [00:03]" "Prompt executed in 9.47 seconds" "loaded completely; 13267 MB"
프로그레스 바(████)가 보이면 ComfyUI
Terminal 2: AI_Generator (This App)
"Uvicorn running on http://0.0.0.0:8000" "GET /api/health HTTP/1.1" 200 OK "POST /api/batch/start HTTP/1.1" 200 OK "GET /api/batch/status HTTP/1.1" 200 OK "Shutting down"
/api/ 로그가 보이면 AI_Generator

How to Run

1

ComfyUI 실행 (터미널 1)

cd D:\Projects\ComfyUI
python main.py --listen --disable-xformers

✅ "To see the GUI go to: http://0.0.0.0:8188" 메시지 확인

2

AI_Generator 실행 (터미널 2)

cd D:\Projects\AI_Generator
.venv\Scripts\activate
python app.py

✅ "Uvicorn running on http://0.0.0.0:8000" 메시지 확인

3

브라우저 접속

http://localhost:8000

✅ 좌측 하단 "ComfyUI Live" 초록색 확인

또는 한번에: D:\Projects\AI_Generator\run_studio.bat 실행

Shutdown / Restart

Troubleshooting

ComfyUI Errors

CUDA error ... invalid argument

→ --disable-xformers 플래그 추가

ModuleNotFoundError: triton

→ 무시 가능 (경고만, 동작 정상)

AI_Generator Errors

Cannot connect to 127.0.0.1:8188

→ ComfyUI가 안 돌고 있음. 먼저 실행

Timeout (300s)

→ 정상. 첫 1장만 느림 (모델 로딩)

Browser Errors

Unsafe attempt to load URL

→ 새 탭에서 localhost:8000 직접 입력

ComfyUI Offline (빨간 점)

→ ComfyUI 터미널 확인 후 재실행

📌 CSV Format Guide

Create a CSV file in kemi/prompts/ folder.

Required Columns:
  • desc_ko: Korean description (Target file name)
  • prompt: Main English prompt
Optional Columns:
  • aspect_ratio: '16:9', '9:16', '1:1', '4:3', '21:9', etc.
  • seed: Fixed seed number
  • extra_positive: Additional style tags
  • extra_negative: Specific exclusions
Advanced: Wildcards (Randomization)

Use curly braces {} to pick random options per generation.

  • {red|blue|green} : Picks one color randomly.
  • {standing|sitting|flying} : Varies the pose.
desc_ko,prompt,aspect_ratio
